App
A web path relative to the ArozOS root, or an image URL.
How it is served
Path On this address: /app/<name>/. Nothing to set up.
Subdomain On its own host name, e.g. app.example.com. Isolated from ArozOS.
In path mode the app shares the ArozOS address. Its web pages can act as the signed in user on ArozOS, so only use it for software you trust. Choose subdomain mode for anything else.
Point this name at the same server as ArozOS (a DNS record, or a public hostname in Cloudflare Tunnel). Cloudflare's free certificate only covers one level, so prefer app.example.com or app-nas.example.com over app.nas.example.com.
Where users sign in before being sent to the app.
