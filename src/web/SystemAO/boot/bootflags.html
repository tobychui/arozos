Runtime
Adjust startup parameters while the system is running. Changes are saved and restored on every boot.
General
Host Name -hostname
Name shown to users and on the local network. Network discovery picks up a new name after a restart.
Upload & File I/O
Max Upload Size -max_upload_size
Largest file a user can upload. Must not exceed the memory available on this host.
MB
File Upload Buffer -upload_buf
Uploads larger than this are buffered to disk instead of memory (slower).
MB
File IO Buffer -iobuf
Memory used for each file operation. Default is 1024.
Bytes
Web Services
Disable IP Resolver -disable_ip_resolver
Do not try to analyze the client IP address. Useful when the server is hosted behind NAT or a reverse proxy.
Enable Home Page -homepage
Allow users to host their own static web pages.
Enable Directory Listing -dir_list
Allow listing the contents of a directory if the request URL is a folder.
Saved values are restored when the system starts. A value passed as a start parameter (for example -hostname) takes priority: it replaces the saved value on that boot. Settings marked with their flag name were set this way.
