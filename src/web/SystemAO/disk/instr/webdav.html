Login Method for macOS

If you are using macOS, select "Connect to Server" in Finder, enter the endpoint of the ArozOS WebDAV service ({url}) and sign in with your ArozOS username and password. Each of your storages shows up as a folder.

Login Method for Windows (Non SSL / TLS Mode)

Windows no longer connects to WebDAV without TLS since Windows 10. To use WebDAV on Windows, you need a certificate installed or a reverse proxy with TLS / SSL support.

  1. Use a reverse proxy server like Zoraxy to proxy WebDAV traffic with TLS enabled
  2. Click "Map Network Drive" in the This PC toolbar of File Explorer
  3. Enter {url} as the folder
  4. Sign in with your ArozOS username and password
