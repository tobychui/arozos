Send photos from your phone

An automation on your phone, such as an iOS Shortcut that runs every night, uploads your new photos and files to the address below. They go to a folder of your drives, sorted the way you pick. The phone may send the same files again on every run: files that are already here are skipped.

Set up an iPhone or iPad
  1. Open Shortcuts, go to the Shortcuts tab and tap + to make a shortcut. Name it, for example, Sync Photos to ArozOS.
  2. Add the Find Photos action. Tap Add Filter and set Date Taken, is in the last, 3 days. A longer time than the automation needs does no harm: the server skips what it already has.
  3. Add Repeat with Each, which repeats with each item in Photos.
  4. Inside the repeat, above End Repeat, add Get Contents of URL with the upload address above. Open its options and set Method to POST.
  5. Under Headers add two headers: the key Username with your user name, and the key Authorization with the word Bearer, a space and your password. Both are in the table above.
  6. Set Request Body to Form, add a new field of the type File, name it file and pick Repeat Item as the file. No other field is needed.
  7. Run the shortcut once with the play button and allow it to use your photos and to connect to the server. The Activity above then shows what arrived.
  8. To run it every night, go to the Automation tab, tap +, choose Time of Day, pick a time when the phone is usually charging, Daily and Run Immediately, then choose the shortcut.
  • Optional: add a Text field named date, insert the Repeat Item variable, tap it, choose Date Taken and set its date format to ISO 8601. The server reads the date from photos and videos itself, so this only matters for files without one.
  • Long videos can stop a shortcut that runs in the background. If that happens, add the filter Media Type is Image to Find Photos.
  • A proxy in front of this server may refuse large uploads before they arrive. Cloudflare refuses requests over 100 MB.
  • To test your password, open the upload address in a browser and sign in with your user name and password. The answer starts with "ok": true.
  • On Android, automation apps such as HTTP Shortcuts, Tasker or Automate can send the same request.
