Open your ArozOS drives in File Explorer

Each drive appears as a network share. In Windows, type an address below into the File Explorer address bar. On a Mac, choose Go, then Connect to Server, in Finder.

This server is new and experimental. Keep a backup of anything you cannot afford to lose.
Set your SMB password
Windows cannot sign in with your ArozOS password, so SMB has a password of its own. Make it different from your login: SMB stores it in a weaker form.
Save this password now, it is not shown again.
