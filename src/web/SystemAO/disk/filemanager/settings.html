How the File Manager looks and behaves for your account. Changes are saved as you make them.
Appearance
Theme
Shared with the desktop and the other system apps.
Operation toolbar
Show the classic row of file operation buttons above the file list. Not shown on phones.
Show hidden files
List files and folders whose names start with a dot.
View
Opening view
Uploads
Close the upload list when done
Clears the list a moment after the last task finishes. A failed task keeps it open so you can retry it.
Trash Bin
Automatic Removal
Files in the trash bin are permanently removed once they are older than this. Turn it off to keep them until you empty the bin yourself.
Trash Bin Size Limit
When the limit is reached, deleting a file will ask you whether to empty the bin first, delete the file outright, or cancel.
