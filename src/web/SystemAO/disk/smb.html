After turning the server on, every user who wants SMB, you included, sets their own SMB password in the Connect section above. Nobody can connect until they have.
File Explorer can only use port 445. Any other port needs Windows 11 24H2 or newer and a command to connect.
Leave this off to keep SMB on private networks. Port 445 should never be reachable from the internet.
Lists it in the Network view of Windows File Explorer (port 445 only) and in the macOS Finder sidebar.
Files deleted over SMB can then be restored from the trash bin of the web desktop. Temporary files of Office and other programs are still deleted for good, and so is everything once a user's bin is full.
Encrypts everything sent over the network, file contents and names included. Clients that cannot encrypt, such as Windows 7 and older Linux and macOS versions, can no longer connect, and transfers get somewhat slower.
S3, FTP, WebDAV and cluster drives only move whole files, so a file opened over SMB is first copied to this server's temporary folder. Larger files are refused. 0 means no limit.
